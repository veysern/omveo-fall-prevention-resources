# Omveo Fall Prevention Resources

Open data, scripts, and resources for senior fall prevention research.

Maintained by the team at [Omveo](https://omveo.co), a fall detection 
smartwatch company.

## About

Omveo was built after our founder's father had a fall at age 71. We've 
been collecting public data on senior falls, hospital costs, and prevention 
strategies. This repo contains some of that work.

## Contents

- `cdc_fall_stats.csv` — CDC public fall data, parsed and cleaned
- `python_parser.py` — simple parser for CDC HCUP data
- `fall_prevention_checklist.md` — public domain fall prevention checklist
